# Expense Tracker

A simple web application to record daily expenses, categorize spending, and calculate the total amount in real time using HTML, CSS, and JavaScript.

## Features

- **Add Expenses:** Enter an expense name, amount (in ₹), and choose a category (`Food`, `Travel`, `Shopping`, `Education`, or `Other`).
- **Live Expense List:** Displays each added expense dynamically on the page using JavaScript DOM manipulation.
- **Automatic Total Calculation:** Updates the total expense amount automatically whenever a new entry is added.

## Technologies Used

- **HTML5** – Structure of the form and expense display section
- **CSS3** – Layout and basic styling
- **JavaScript (DOM Manipulation)** – Handling form submission, creating list items dynamically, and updating the total
